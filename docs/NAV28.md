\
Where Next? Advance Topics for Clever Git Heads\
\
Rebasing: The git rebase command lets us modify the commit history by moving\
or combining a sequence of commits to a new base commit.\
\
Cherry-Picking: This is a powerful command that enables arbitrary Git commits to\
be picked by reference and appended to the current branch.\
\
Bisecting: Git bisect is a binary search algorithm for finding the commit that\
introduced a bug.\
\
Reflog: Git includes a reference log or "reflog" — a log of where your HEAD and\
branch references have pointed.\
\
Submodules: Submodules allow you to keep a Git repository as a subdirectory of\
another Git repository.\
\
Hooks: Hooks are scripts that Git executes before or after events such as:\
commit, push, and receive.\
\
Git Large File Storage (LFS): Git extension to allow the versioning large files.\
Replaces large binary files with text pointers inside Git, while storing the file\
contents separately.
